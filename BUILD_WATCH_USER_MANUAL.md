# INTRODUCTION

## What is Build Watch?

Build Watch is the official web-based Project Monitoring and Evaluation System (PMES) for the Municipality of Santa Cruz, Laguna. It provides transparent, real-time tracking of infrastructure projects and social development programs.

## Purpose of This Manual

This manual provides step-by-step instructions for using Build Watch, covering all public pages and user roles. Use it as your reference guide for navigating the system efficiently.

## System Requirements

- **Browser:** Chrome, Firefox, Safari, or Edge (latest version)
- **Internet:** Stable internet connection
- **Device:** Computer, tablet, or smartphone
- **Screen:** Minimum 1024px width for optimal experience

# SYSTEM OVERVIEW

## User Roles

Build Watch supports six unique user accounts:

1. **EIU** (External Implementing Unit) - Blue Theme
2. **LGU-IU** (LGU Implementing Unit) - Yellow Theme
3. **MPMEC** (Municipal Project Monitoring and Evaluation Committee) - Red Theme
4. **MPMEC Secretariat** - Red Theme
5. **Executive Viewer** - Executive Blue Theme
6. **System Admin** - Dark Theme

## Login Access

All users access the system through a single login page:
- **URL:** `/login/lgu-pmt`
- **Default Password:** `LGU_Pass` (change on first login)

## 1. Cannot Log In

**Problem:** Unable to log in with correct credentials.

**Quick Fix:**
1. Verify username and password are correct (case-sensitive)
2. Clear browser cache and cookies
3. Try a different browser
4. Check internet connection
5. Contact System Admin if problem persists

## 2. Dashboard Not Loading

**Problem:** Dashboard page shows blank or takes too long to load.

**Quick Fix:**
1. Refresh the page (F5 or Ctrl+R)
2. Check internet connection speed
3. Clear browser cache
4. Disable browser extensions temporarily
5. Try incognito/private browsing mode
6. Contact System Admin if issue continues

5. Clear browser cache
6. Contact System Admin if problem persists

# SCREENSHOT GUIDELINES

## Resolution Requirements

- **Minimum Resolution:** 1920x1080 pixels (Full HD)
- **Recommended Resolution:** 2560x1440 pixels (2K) or higher
- **Aspect Ratio:** 16:9 (landscape) for dashboard screenshots
- **File Format:** PNG (preferred) or JPG
- **Color Mode:** RGB

## Cropping Rules

1. **Remove Browser UI:** Crop out browser address bar, bookmarks, and taskbar
2. **Focus on Content:** Include only relevant page content
3. **Consistent Margins:** Maintain 20-30px margins around content
4. **Full Page vs. Section:** 
   - Use full page for overview screenshots
   - Use section crop for specific features

## Highlighting Guidelines

1. **Use Red Arrows:** Point to important elements
2. **Red Boxes:** Highlight key areas (use 2-3px red border)
3. **Annotations:** Add text labels for clarity
4. **Consistency:** Use same highlighting style throughout manual

## Filename Format

**Format:** `XX_role_page-element_description.png`

**Components:**
- **XX:** Two-digit photo number (01, 02, 03...)
- **role:** public / EIU / LGU-IU / MPMEC / Secretariat / ExecViewer / SysAdmin
- **page-element:** Short hyphenated description (e.g., `dashboard-overview`, `submit-update-form`)
- **description:** Brief feature description

**Examples:**
- `01_public_home-page_main-hero.png`
- `17_EIU_dashboard_statistics.png`
- `34_Secretariat_submissions-tracker_dashboard.png`

## Screenshot Checklist

Before taking a screenshot:
- [ ] Browser is in full-screen mode
- [ ] Page is fully loaded
- [ ] No personal/sensitive data visible
- [ ] Content is centered and clear
- [ ] Highlighting/annotations added if needed
- [ ] Filename follows naming convention
- [ ] Screenshot saved in correct folder
